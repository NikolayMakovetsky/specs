## 📖 О проекте

«Менторинг» — это фича для корпоративной ERP-системы, которая помогает:

- 🧑‍🎓 **Сотрудникам (менти)** находить наставников для профессионального роста.
- 🧑‍🏫 **Менторам** управлять своими подопечными и фиксировать прогресс.
- 👩‍💼 **HR-менеджерам** контролировать процесс, назначать пары и видеть общую статистику.

Проект создавался как комплексный пет-проект для демонстрации навыков системного анализа, проектирования и документирования.

## 🎯 Цель проекта

Создать портфолио, демонстрирующее навыки системного аналитика:

- Сбор и анализ требований
- Моделирование бизнес-процессов (BPMN)
- Проектирование сценариев (Use Case)
- Разработка модели данных (ER-диаграмма)
- Спецификация REST API (OpenAPI)
- Прототипирование интерфейсов (Figma)
- Написание технического задания (ТЗ)

## 🚀 Как запустить мок-сервер

Если вы хотите посмотреть, как работает API (даже без реального бэкенда), можно запустить мок-сервер с помощью Prism.

### 1. Установите Node.js и npm
Скачайте и установите Node.js с [официального сайта](https://nodejs.org/).

### 2. Установите Prism глобально
```bash
npm install -g @stoplight/prism-cli
```

### 3. Запустите мок-сервер
Перейдите в папку проекта и выполните:
```bash
cd ...
prism mock openapi.yaml
```

### 4. Проверьте работу API
Откройте в браузере:
```
http://127.0.0.1:4010/users
```
Вы должны увидеть тестовый JSON-ответ.

### 5. Тестируйте через REST Client
Используйте файл [`test-api.http`](./test-api.http) с расширением **REST Client** в VSC для удобного тестирования всех эндпоинтов.
