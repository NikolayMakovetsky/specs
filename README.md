## 🛠 Стек технологий и инструментов

### Нотации моделирования
- **BPMN 2.0** — моделирование бизнес-процессов
- **UML** — Use Case, Sequence, ER-диаграммы

### Языки и форматы данных
- **Java 17+** — разработка бэкенда
- **SQL** — проектирование и работа с БД
- **JSON** — обмен данными (REST API)
- **YAML/OpenAPI** — спецификация API
- **Groovy** — скрипты в Camunda

### Инструменты и платформы
| Инструмент | Назначение |
|------------|------------|
| **Camunda Platform 7.24.0** | BPMN-движок |
| **Camunda Modeler** | Визуальное моделирование процессов |
| **Spring Boot 3.2.4** | Веб-фреймворк |
| **H2 Database** | Встроенная СУБД |
| **Postman / REST Client** | Тестирование API |
| **Draw.io** | Создание диаграмм |
| **Figma** | Прототипирование интерфейсов |
| **Stoplight Prism** | Мок-сервер для API |
| **Git** | Контроль версий |
| **Markdown** | Документация |
| **Maven** | Сборка проектов |

### Методологии
- Гибкие методологии (Scrum)
- Сбор и анализ требований
- Декомпозиция задач
- Документирование API и процессов
