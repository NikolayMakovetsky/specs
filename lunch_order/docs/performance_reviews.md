## 1. Общие условия

1.1. Оценка предварительная, для одного fullstack-разработчика, с учётом аналитики, разработки, тестирования и правок.

1.2. Точность оценки: **±30%**.

1.3. Итоговая оценка: **~820 ч/ч** (диапазон: 574–1066 ч/ч).
