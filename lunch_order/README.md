# Заказ обедов — Модуль корпоративного питания

Модуль для корпоративного веб-портала, который позволяет сотрудникам заказывать обеды из нескольких столовых, а администратору — управлять меню, заказами, пользователями и отчётами.

---

## О проекте

Компания организует питание сотрудников через несколько столовых по договорам. Сейчас процесс заказа ручной: администратор собирает меню по email, сотрудники отвечают письмами, администратор вручную агрегирует заказы и передаёт их заведениям. Это трудоёмко, подвержено ошибкам и не даёт истории для анализа.

Модуль решает эту проблему: сотрудник выбирает столовую и блюда на дату через личный кабинет, администратор загружает меню из Excel и управляет заказами, а система хранит историю заказов по заведениям.

## Ключевые особенности

- **Роли:** Сотрудник, Администратор, Супер-администратор (сквозная), Гость-Сотрудник, Гость-Администратор.
- **Два режима работы:** в составе корпоративного портала (рабочий) и в составе демо-портала (демонстрационный).
- **Импорт меню из Excel:** универсальный парсер с настройкой маппинга колонок, отдельный формат для каждой столовой + эталонный шаблон.
- **Гибкая логика заказа:** одна позиция из категории, составные блюда с гарнирами, «Обед не нужен», заказ на неделю, дозаказ.
- **Отчёты:** по категориям столовой и по сотрудникам, PDF на сервере.
- **Автоматическая очистка данных** по параметру `retention_days`.
